About 35 seconds. The result: with one family hidden, the other families’ map identified its concepts correctly 97 percent of the time in the middle layers. With the labels shuffled, or with random directions, it drops to 6 percent, which is chance. So the shared map is real, not a pattern any set of directions would show. One example: in 29 of 35 models, the concept most closely tied to credibility is formality. If asked whether the pairs really capture credibility: the test does not depend on what the label means. Whatever a set of pairs picks out, it picks out the same thing, in the same relation to the other 16, in every model. That is the finding; what to call each concept is a separate question.
